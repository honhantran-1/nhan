# Easy Python – SwiftUI starter

1. Xcode > File > New > Project > iOS App (SwiftUI), product name **EasyPython**, iOS 16+.
2. Delete the template `ContentView.swift` and the template `@main` App file.
3. Drag these files into the project: EasyPythonApp, Models, ProgressStore, CourseData, Views (.swift).
4. Add a bookshelf-in-a-library photo to Assets.xcassets named `LibraryBookshelf`.
5. Run on a simulator or device.

Add lessons or quiz questions by editing `CourseData.swift` only.
